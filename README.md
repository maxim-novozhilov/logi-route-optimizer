## 🎯 Overview
LogiRoute is a hybrid Decision Support System (DSS) designed for automated fuel logistics. It bridges the gap between high-level AI commands and rigorous mathematical optimization.

## 🚀 Key Features
* **Mathematical Core:** Powered by Google OR-Tools (VRPTW - Vehicle Routing Problem with Time Windows).
* **Triple-Layer Filtering:**
    1.  **Nominal Filter:** Automatically excludes sites with sufficient fuel (>80%).
    2.  **Policy Filter:** Skips sites under maintenance or decommissioning (Business Rules).
    3.  **Dispatcher Overrides:** Real-time AI-driven blocking/forcing via Natural Language.
* **Optimization Modes:**
    * **STRICT:** Ensures all priority sites are met within narrow time windows.
    * **FALLBACK:** Intelligent "best-effort" routing that sacrifices low-priority sites to save critical ones if constraints are too tight.
* **Analytics:** Detailed JSON diagnostics explaining why every single site was either routed or dropped.

## 🛠 Tech Stack
* **Backend:** Python 3.10+
* **Solver:** Google OR-Tools
* **API:** FastAPI / Uvicorn
* **AI Integration:** OpenRouter (Llama 3 / Mistral)
* **Frontend:** Vanilla JS / Leaflet.js (Modern SaaS UI)

## 📂 Data Structure & Mock Files

The project uses the `mock_data/` directory to store both input configurations and generated results.

### Input Data (The "Before")
* `sites_100.csv`: Raw telemetry data for 100 fuel sites (site status, fuel levels, priorities).
* `fleet.json`: Configuration of the available vehicle fleet (capacities, shift times, start/end locations).
* `distance_matrix.json`: Pre-computed travel times and distances between all nodes.
* `dispatch_overrides.json`: Real-time constraints injected by the AI Dispatcher (blocks/forces).

### 🔄 Intermediate Data
* `telemetry.json`: The processed output of the `parse_telemetry.py` script. It converts raw CSV data into a structured format that the solver understands, calculating fuel needs in liters and assigning operational priorities.

### Reference Output (The "After")
* `route_solution.json`: **The Core Result.** A comprehensive JSON generated by the solver. It includes:
    * **Success/Fallback status:** Indicates if the optimal route was found under strict or relaxed constraints.
    * **Vehicle Routes:** Precise turn-by-turn schedules for every truck.
    * **Diagnostic Arrays:** Detailed lists of skipped sites (`skipped_nominal`, `skipped_by_policy`, `overweight_for_single_vehicle`) to ensure 100% operational transparency.

## ⚙️ Configuration

The system uses environment variables for AI integration and server settings. 
To set up the project:

1. Create a `.env` file in the root directory (use `.env.example` as a template).
2. Add your **OpenRouter API Key** to enable the AI Dispatcher.
3. Specify the model you wish to use (default is `llama-3.3-70b`).
